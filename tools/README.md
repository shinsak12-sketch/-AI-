# 마스킹 스튜디오 (masking-studio.html)

엑셀/CSV 개인정보를 자동으로 비식별화하는 **완전 오프라인 단일 HTML 도구**.

## 쓰는 법
`masking-studio.html` 파일을 브라우저로 열기만 하면 됨. 설치·서버·인터넷 전부 불필요.

1. 파일 올림 (xlsx / xlsm / xls / csv, EUC-KR CSV도 자동 인식)
2. 가릴 열 체크 — 유형은 자동 감지되고 `자동 추천` 버튼으로 한 번에 켜짐
3. `마스킹 실행`
4. 파일 2개 내려받음
   - `*_masked.xlsx` — 외부에 보낼 파일
   - `*_mapping.xlsx` — 원본↔마스킹 대응표 (외부 반출 금지)
5. 결과가 돌아오면 [복원] 탭에서 결과 파일 + 매칭 파일을 올려 원래 값으로 되돌림

## 마스킹 모드
- **형태유지** — 자릿수·구분자·글자종류를 그대로 두고 값만 바꿈.
  `홍길동 → 채민서`, `010-1234-5678 → 010-8471-2093`, `hong@abc.com → k7x2mq@abc.com`
- **토큰** — `NAME_0001` 식 일련번호. 접두어는 열마다 수정 가능

## 보장 사항
- 같은 원본값은 파일 전체에서 항상 같은 값으로 치환 → 마스킹 후에도 집계·피벗·중복제거 결과가 원본과 동일
- 서로 다른 원본값이 같은 마스킹값으로 겹치지 않음 → 복원 100% 정확
- 마스킹값이 원본값과 우연히 일치하지 않도록 회피
- 고르지 않은 열이라도 문장 속에 섞인 원본값을 함께 치환 (옵션, 기본 켜짐)
- 선택한 시트만 처리하고 나머지 시트는 원본 그대로 보존

## 지원 유형
이름 · 전화번호 · 이메일 · 주민등록번호 · 카드번호 · 계좌번호 · 주소 · 사번/ID · 숫자 · 날짜 · 일반 텍스트

## 기술 메모
- 파일 크기 약 920KB — 오프라인 동작을 위해 SheetJS(xlsx) 0.18.5를 파일 안에 내장함
- 네트워크 전송 코드 자체가 없음. 모든 처리는 브라우저 메모리에서만 일어남
