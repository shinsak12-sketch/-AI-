# 마스킹 스튜디오 (masking-studio.html)

엑셀/CSV 개인정보를 비식별화하는 **완전 오프라인 단일 HTML 도구**.
파일을 브라우저로 열기만 하면 됨. 설치·서버·인터넷 전부 불필요하고, 올린 파일은 브라우저 메모리에서만 처리됨.

## 화면 구성

| 왼쪽 — 입력 | 가운데 — 설정 · 결과 | 오른쪽 — 실행 |
|---|---|---|
| 파일 올리기 (여러 개 가능)<br>매칭 파일 이어쓰기<br>편집할 파일 고르기 (같은 양식 자동 묶음) | **열 설정** (세로 목록, 여러 열 일괄 적용)<br>**미리보기** (샘플 20행)<br>**결과** (통계·점검·파일별 받기를 가로로) | 묶기 기준 · 문장 속 치환<br>마스킹 실행 `Ctrl+Enter`<br>결과 요약 · 바로 받기 |

화면은 **항상 3분할**. 창이 1360px보다 좁으면(노트북 배율, 창 절반 등) 세로로 쌓지 않고 화면 전체를 비율대로 줄여서 같은 배치를 유지함.
상단 제목 옆에 `v2 · 3분할` 표시가 있으면 이 버전임.

## 핵심 기능

### 같은 양식 파일 여러 개를 한 번에
파일을 여러 개 올리면 **열 구성이 같은 파일끼리 자동으로 묶임**. [묶어서 설정]이나 체크박스로 여러 파일을 고르면
가운데서 한 번 바꾼 설정이 **고른 파일 전부**에 적용됨. 양식이 다른 파일을 섞어 고르면 **이름이 같은 열끼리** 함께 바뀜.

### 열 여러 개를 한꺼번에
열 줄을 누르거나 체크하면 선택되고 `Shift`로 범위 선택. 위에 뜨는 일괄 바에서
켜기·끄기·방식·유형·기간 단위·기준일을 한 번에 적용. [유형으로 고르기]로 예컨대 날짜 열만 한꺼번에 고를 수 있음. 해제는 `Esc`.

### 방식 5가지
| 방식 | 예 | 매칭표·복원 |
|---|---|---|
| 형태유지 | 홍길동 → 서지우 | O |
| 토큰 | `NAME_0001` | O |
| 비식별 | `PHONE-JTENHQ` — 숫자·@ 없음, 개인정보 형식으로 안 읽힘 (전화·주민·카드·계좌·이메일 기본값) | O |
| **기간** | 생년월일 → 만 나이 · 연령대 · 년 · 개월 · 일 | X |
| 삭제 | 공란 또는 `●●●` | X |

### 기간 계산
날짜를 **기준일까지의 기간**으로 바꿈. 생년월일을 만 나이로 바꾸면 분석엔 쓰면서 날짜는 사라짐.
- 단위: 만 나이 / 연령대(30대) / 년 / 개월 / 일. 기준일은 열마다 지정 (기본 오늘)
- 읽는 형식: `1990-01-05` `1990.1.5` `19900105` `1990년 1월 5일` `900105`, **주민등록번호**(뒷자리 첫 숫자로 세기 판별), 엑셀 날짜
- 날짜가 기준일보다 뒤면 음수. 못 읽은 값은 빈칸 처리하고 개수·예시를 알려줌
- 머리글에 `생년월일(만나이·기준 2026-11-25)`처럼 표시됨
- 머리글이 생년월일·생일·출생일인 열은 처음부터 "만 나이"로 켜짐

### 같은 값 = 같은 코드
코드는 **값에만** 달림. 행·열·파일이 달라도 같은 값이면 같은 코드라 마스킹 후에도 집계·피벗·조인이 그대로 됨.
묶는 기준: 끔 / **기본**(공백·전각반각 무시) / 강하게(기호·대소문자 무시, `(주)`=`㈜`=`주식회사`).

### 이전 매칭 파일 이어쓰기
이미 마스킹해서 보낸 결과가 있고 **다른 파일을 추가로** 마스킹할 때, 그때 받은 매칭 파일을 넣으면
거기 있던 값은 **예전과 같은 코드**를 받고 처음 보는 값만 새 코드를 받음. 여러 개를 넣으면 합쳐 씀
(같은 코드가 서로 다른 값에 쓰인 항목은 복원이 꼬이므로 빼고 알려줌).
새 매칭 파일엔 이전 코드까지 **누적**되므로 늘 마지막 매칭 파일 하나만 챙기면 됨.

### 받기
파일마다 마스킹 파일 + 공통 매칭 파일 1개. 여러 파일이면 **[마스킹 파일 전부 (ZIP)]** —
ZIP엔 매칭 파일이 **안 들어감**(실수로 같이 보내지 않게). 한글 파일명이 깨지지 않도록 UTF-8 표시를 세운 ZIP을 직접 만듦.
파일은 실행 직후 백그라운드에서 미리 만들어 두므로 누르면 바로 받아짐.

### 그 밖에
- 개인정보 형식 점검: 결과 전체(고르지 않은 열 포함)에 전화·주민·카드·계좌·이메일 형식이 남았는지 보고, 버튼 하나로 비식별 전환·재실행
- 문장 속 치환: 비고처럼 안 고른 열에 섞인 같은 값도 바꿈 (열 단위로 켠 값만 대상, 행 통째 마스킹 값은 안 번짐)
- 행 통째 마스킹: 미리보기에서 행 번호를 누름
- 복원: 결과 파일 여러 개 + 매칭 파일 → 원래 값. 문장 속 코드도 복원 가능
- 다른 시트는 원본 그대로 보존, CSV는 EUC-KR 자동 인식·BOM 붙여 저장

## 성능 (30만 행 × 10열 CSV)
| 구간 | 시간 |
|---|---|
| 파일 읽기 → 목록 표시 | 0.44초 |
| 열 켜기/끄기·방식 변경 반응 | 6~8ms |
| 마스킹 (180만+ 셀, 기간 계산 포함) | 9.3초 |
| 다운로드 파일 준비 (백그라운드) | 1.7초 |
| 다운로드 클릭 → 저장 | 0.16초 |

## 수정하는 법
`masking-studio-src/` 의 분할 소스를 고친 뒤 빌드:

```
python3 tools/masking-studio-src/build.py
```

| 파일 | 내용 |
|---|---|
| `shell.html` | 화면 골격 · 디자인 (CSS) |
| `a-util.js` | 공통 도구 · 기간 계산 · ZIP 작성기 |
| `engine.js` | 유형 감지 · 값 생성기 · 형식 점검 · 값 묶기 · CSV/엑셀 읽기 |
| `b-ui.js` | 상태 · 파일 목록 · 열 설정 · 미리보기 |
| `c-run.js` | 마스킹 엔진 · 결과 · 받기 · 이어쓰기 |
| `worker.js` / `d-rest.js` | 백그라운드 빌더 · 복원 · 사용법 · 단축키 |

내장 라이브러리 SheetJS 0.18.5(Apache-2.0)는 빌드 때 기존 `masking-studio.html`에서 꺼내 다시 씀.
